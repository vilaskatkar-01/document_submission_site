## 📋 Project Overview
DocSubmit is a web-based document submission system that allows users to upload documents, track their status, and receive notifications. It includes role-based access control with Admin and Submitter roles.

---

## ✨ Features

### 🔐 User Management
- User registration with email
- Secure login/logout
- Two roles: Admin & Submitter
- Password hashing for security

### 📤 Document Management
- Upload documents with categories
- Track document status (Pending/Approved/Rejected)
- Admin can approve or reject documents
- Users can only see their own documents
- Search and filter functionality

### 📊 Dashboard & Analytics
- View all submitted documents
- Statistics cards (Total, Approved, Rejected, Pending)
- Search by filename
- Filter by status and category
- Responsive design
