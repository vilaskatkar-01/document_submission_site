# 📄 Document Submission System


-----------------------------------
Created By: VILAS BALASAHEB KATKAR
-----------------------------------


A web-based document submission system built with Flask, SQLite, and Python.

## ✨ Features
- 🔐 User Registration & Login
- 👥 Role-based Access (Admin/Submitter)
- 📤 Document Upload with Categories
- 📊 Dashboard with Statistics
- 🔍 Search & Filter Documents
- ✅ Document Status Tracking (Pending/Approved/Rejected)
- 📧 Email Notifications
- 🎨 Responsive UI Design

## 🛠️ Technologies Used
- Python 3.13
- Flask
- SQLite3
- Flask-Login
- Flask-Mail
- HTML5, CSS3, JavaScript
